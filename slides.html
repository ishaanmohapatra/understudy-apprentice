The Apprentice Test

When to askUnasked event + 2.5s no input + 1.5s silence + agent quiet + 20s cooldown. Keystrokes say "don't barge in."
What to askOnly why / limits / exceptions / "when do you stop and ask someone". Never what's visible. Topics never repeat — enforced in code.
Understood?Every gap ends answered / deferred to a named person / unresolved — then a confirmed teach-back. Deferrals never count as answered.

How it works

Vision turns the screen into observations → plain code checks them against confirmed rules → the agents only talk and ask.

Two ElevenLabs agents (interviewer + tutor, skip_turn, Expressive Mode) · Claude Haiku on frames · one careful Claude Sonnet call for the draft map · closed rule vocabulary — anything else becomes an open question, never a guess.
