## 5 · How it works
Vision turns the screen into observations · plain code checks observations against
confirmed rules · the agents only talk and ask. Two ElevenLabs agents (interviewer,
tutor) with skip_turn; Expressive Mode; Claude Haiku for frames; one careful Claude
Sonnet call for the draft map. Only rules the expert confirmed ever reach the tutor.
**Signature proof:** Sabine says "it's 4,000 now" → Work Map v2 supersedes v1 → a
€4,500 invoice is blocked with **no code change**.

## 6 · Moonshot — people first, then agents
Every confirmed Work Map is both a course for new hires **and** a read-only rulebook an
AI agent can load (one click: Export Work Map JSON). Agents take the routine steps and
stop exactly where the expert would. Today: one task. Next: a living company memory
that only asks about what changed.
